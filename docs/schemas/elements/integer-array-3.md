# integer-array-3

<SchemaUri uri="schema/elements/integer-array-3/1.0.1/integer-array-3.schema.json" />

Array of integer values with three values per row (N×3). Extends [integer-array-md](integer-array-md.md) with a fixed width of 3. Supports int32 and int64 encoding.

**See also:** [integer-array-md](integer-array-md.md) (base type), [integer-array-1](integer-array-1.md), [integer-array-2](integer-array-2.md) (other widths).

## Properties

Properties are inherited from [integer-array-md](integer-array-md.md) with `width` constrained to 3.
