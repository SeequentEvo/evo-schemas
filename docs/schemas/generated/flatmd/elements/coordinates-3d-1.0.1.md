### coordinates-3d (v1.0.1)
A single point in 3D space. The x, y, z values follow the axis order of the object's coordinate_reference_system.

| Property | Type | Description | Flags |
|---|---|---|---|
| x | Number | Position along the first axis (x) of the object's coordinate reference system. | ✅ |
| y | Number | Position along the second axis (y) of the object's coordinate reference system. | ✅ |
| z | Number | Position along the third axis (z) of the object's coordinate reference system. | ✅ |


#### Legend

| Flag | Description |
| --- | --- |
| ⬆️ | Inherited property |
| ✅ | Required property |
