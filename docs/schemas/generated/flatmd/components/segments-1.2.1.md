### segments (v1.2.1)
Segments are defined by pairs of indices into the vertices list.

| Property | Type | Description | Flags |
|---|---|---|---|
| vertices | [segments](../components/segments-1.2.1-vertices.md) | Vertex coordinates. Columns: x, y, z (the first, second, and third axes of the object's coordinate_reference_system). | ✅ |
| indices | [segments](../components/segments-1.2.1-indices.md) | 0-based indices into the vertices. Each pair is a segment. Columns: n0, n1. | ✅ |
