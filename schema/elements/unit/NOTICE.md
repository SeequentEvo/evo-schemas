# Attribution for unit schemas

The following Energistics® products were used in the creation of this work: Energistics Unit of Measure Standard v1.0.1 (Energistics Unit of Measure Dictionary V1.0).

The unit enumerations in this directory are derived from that product. The derivation extracts unit symbols and unit dimension names only; it does not reproduce conversion factors, base units, canonical units, quantity classes, integer codes, prefixes, unit names, unit descriptions or mapping sets.
